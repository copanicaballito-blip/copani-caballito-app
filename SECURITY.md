# Política de seguridad

## Reportar una vulnerabilidad

No publiques vulnerabilidades en Issues públicos. Contactá directamente al owner del repositorio,
`@copanicaballito-blip`, o usá **Security > Report a vulnerability** si está habilitado.

## Reglas del proyecto

- Ninguna clave, token o contraseña se sube al repositorio.
- Los datos personales de empleados o clientes no van en el repositorio: van en la base de datos.
- La única clave que se versiona es `app/debug.keystore`, que solo sirve para que cada APK
  se instale encima del anterior. No protege datos.
